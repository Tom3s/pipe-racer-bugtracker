# Pipe Racer Public Bug Tracker
This is the public, issue-only repo for `pipe-racer`, mainly to track player facing bugs and feature requests.

You can submit a bug or write a feature request [here](https://github.com/Tom3s/pipe-racer-bugtracker/issues/new/choose)

Before writing a bug/feature request:
- Search for similar bugs or feature requests [here](https://github.com/Tom3s/pipe-racer-bugtracker/issues?q=is%3Aissue). If it has already been reported by other, it will immediately get closed
